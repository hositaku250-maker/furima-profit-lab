# フリマ利益計算ラボ（試作版）

## ファイル
- `index.html`: 計算ツール本体。追加ライブラリ不要で動作します。
- `about.html`: 運営者情報のひな形
- `privacy.html`: プライバシーポリシーのひな形
- `contact.html`: お問い合わせページのひな形

## ローカルで確認
`index.html` をブラウザで開いてください。入力を変えると計算結果が更新されます。

## 公開前に必ず確認
1. 運営者情報とお問い合わせ先を実際の内容に更新する。
2. プライバシーポリシーを、導入する解析・広告サービスに合わせて更新する。
3. 手数料の端数処理はサービスごとに異なるため、利用対象サービスの仕様に合わせる。
4. スマートフォン・PCで表示確認し、計算結果を複数パターンでテストする。
5. AdSenseは審査制です。サイトを公開しただけで広告収益が発生するわけではありません。

## 計算式
利益 = 販売価格 - floor(販売価格 × 手数料率) - 送料 - 仕入れ・購入額 - その他費用
利益率 = 利益 ÷ 販売価格 × 100（販売価格が0円の場合は表示しません）

これは試作版です。特定のフリマサービスの公式計算結果を保証するものではありません。
